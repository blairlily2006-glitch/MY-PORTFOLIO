# Immersive Portfolio

沉浸式交互作品集网站，使用 Vite、React、TypeScript、Three.js、GSAP 和 Lenis 构建。

## 本地运行

```bash
pnpm install
pnpm dev
```

## GitHub Pages

仓库推送到 `main` 后会通过 GitHub Actions 自动构建并发布。首次发布前，请在仓库的 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。

素材位于 `public/`。作品展示数据和交互可在 `src/App.tsx` 中维护。
